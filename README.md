# Developer Portfolio

Personal portfolio for Mohsen Mohammed Ali, a junior full-stack developer based in Iraq.

## Live site

[mhsnmn.github.io/developer-portfolio](https://mhsnmn.github.io/developer-portfolio/)

The portfolio highlights [Ansat](https://ansatradio.org/), current projects, technical skills, and verified contact links.

## Local preview

```powershell
python -m http.server 8080
```

Open `http://localhost:8080`.

## Deployment

Push to GitHub. The included workflow publishes the site through GitHub Pages.

In repository settings, select **GitHub Actions** as the Pages source.

## Content notes

- Ansat is volunteer work, not paid client work.
- Keep usage numbers accurate and update them when they change.
- Add only public or sanitized project material.
- Do not commit credentials, member data, or private URLs.
